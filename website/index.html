Open Source

No API keys or environment variables needed. Requires Python 3.9+, at least 8 GB RAM, and ~5 GB disk space for the automatic one-time model download.

cd arb-universal-ide

# 2. Install embedded AI dependencies & launch
pip install llama-cpp-python huggingface-hub
python app.py
